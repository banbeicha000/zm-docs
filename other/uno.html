Windi CSS 是下一代工具优先的 CSS 框架。
可以把 Windi CSS 看作是按需供应的 Tailwind 替代方案，它为你提供了更快的加载体验，完美兼容 Tailwind v2.0，并且拥有很多额外的酷炫功能

UnoCSS ​

INFO

UnoCSS 是一个引擎，而非一款框架，因为它并未提供核心工具类，所有功能可以通过预设和内联配置提供

UnoCSS 属性化简写在 Vue 3 中的实践指南 ​

UnoCSS 的属性化模式（Attributify Mode）极大地提升了模板的可读性，它允许我们将工具类从单一的 class 属性中解放出来，变为更具语义的 HTML 属性。本指南旨在为你提供一份在 Vue 3 项目中常用且强大的属性化简写速查表，特别关注背景渐变、Grid 布局等复杂场景。

前提条件 ​

请确保你的 uno.config.ts 文件中已经引入并使用了以下两个核心预设：

typescript
// uno.config.ts
import { defineConfig, presetUno, presetAttributify } from 'unocss'

export default defineConfig({
  presets: [
    presetUno(), // 或者 presetWind()，功能相似
    presetAttributify(),
  ],
})

核心用法：动态绑定 ​

在 Vue 3 中，我们可以使用 : 或 v-bind 来动态绑定这些属性，这使得根据组件状态切换样式变得异常简单。最常用的方式是三元运算符。

vue
<script setup>
import { ref } from 'vue'
const isActive = ref(false)
</script>

<template>
  <button 
    @click="isActive = !isActive"
    :bg="isActive ? 'blue-500' : 'gray-500'"
    :text="isActive ? 'white' : 'black'"
    p="y-2 x-4"
    border="rounded-lg"
  >
    Toggle Active
  </button>
</template>

常用简写属性速查 ​

1. 背景渐变 (Background Gradients) ​

这是最能体现简写优势的场景之一。

基础用法 ​

  • 语法: bg-gradient="<direction>, from-<color>, to-<color>, (via-<color>)"
  • 方向:
    • to-r (to right), to-t (to top), to-bl (to bottom left), etc.
    • 任意角度: 使用方括号 [163deg]

示例 ​

html
<!-- 从右到左的渐变 -->
<div w-full h-20 bg-gradient="to-r, from-green-400, to-blue-500"></div>

<!-- 45度角，经过一个中间色 -->
<div w-full h-20 bg-gradient="[45deg], from-purple-500, via-pink-500, to-red-500"></div>

<!-- ✨ 你的案例：使用任意颜色和角度 -->
<div 
  w-full h-20 
  bg-gradient="[163deg], from-[#c891ff], to-[#2771fd]"
></div>

终极方案：任意属性值 ​

如果预设的组合无法满足你极其复杂的渐变需求，可以直接写入 CSS 值。注意：CSS 值中的空格需要用下划线 _ 替代。

html
<!-- 直接写入 linear-gradient -->
<div 
  w-full h-20 
  bg="[linear-gradient(163deg,_#c891ff_0%,_#2771fd_100%)]"
></div>

2. 网格布局 (Grid Layout) ​

Grid 布局的属性非常多，属性化模式能让结构一目了然。

容器属性 ​

  • grid: 声明为 grid 容器
  • grid-cols-<n> / grid-rows-<n>: 定义列/行数
  • gap-<n> / gap-x-<n> / gap-y-<n>: 定义间隙

子项属性 ​

  • col-span-<n> / row-span-<n>: 跨越列/行
  • col-start-<n> / col-end-<n>: 指定起始/结束位置
  • row-start-<n> / row-end-<n>

示例 ​

html
<div class="w-full p-4 bg-gray-100 rounded-lg">
  <div grid="~ cols-4 gap-4" text-white text-center>
    
    <!-- A: 跨 2 列 -->
    <div bg="blue-500" p-4 rounded col-span-2>A (col-span-2)</div>
    
    <!-- B: 普通项 -->
    <div bg="green-500" p-4 rounded>B</div>
    
    <!-- C: 普通项 -->
    <div bg="green-500" p-4 rounded>C</div>
    
    <!-- D: 从第 2 列开始，跨 3 列 -->
    <div bg="red-500" p-4 rounded col="start-2 span-3">D (start-2, span-3)</div>

  </div>
</div>

💡 提示: grid="~ ..." 是一个简写，等同于 grid grid-cols-4 gap-4。~ 代表 grid 本身。

3. 弹性布局 (Flexbox) ​

与 Grid 类似，Flexbox 的属性也非常适合属性化。

  • 容器: flex, inline-flex
  • 对齐: items-center, justify-between, content-start
  • 方向与换行: flex-col, flex-row-reverse, flex-wrap
  • 子项: flex-grow, flex-shrink, flex-basis-<n>, order-<n>

示例：一个典型的导航栏 ​

html
<header flex="~" items-center justify-between p-4 bg-gray-800 text-white>
  <!-- Logo -->
  <div font-bold text-xl>MyApp</div>
  
  <!-- Navigation Links -->
  <nav flex="~ gap-4" items-center>
    <a href="#" text="gray-300 hover:white">Home</a>
    <a href="#" text="gray-300 hover:white">About</a>
    <a href="#" text="gray-300 hover:white">Contact</a>
  </nav>
</header>

4. 定位与层级 (Positioning & Z-Index) ​

  • 定位: absolute, relative, fixed, static, sticky
  • 位置: top-0, left-1/2, bottom-4, inset-0 (上下左右都为0)
  • 变换 (常用于居中): transform, translate-x-1/2, scale-105
  • 层级: z-0, z-10, z-auto

示例：居中模态框的遮罩层 ​

html
<!-- 遮罩层 -->
<div 
  fixed 
  inset-0 
  bg="black/50" 
  z-40
>
  <!-- 模态框本体 -->
  <div
    relative
    p-8 bg-white rounded-lg shadow-xl
    top-1/2 left-1/2
    transform="-translate-x-1/2 -translate-y-1/2"
    z-50
  >
    I am a centered modal.
  </div>
</div>

5. 伪类与响应式 ​

这是属性化模式最强大的功能之一，可以轻松组合状态和断点。

  • 语法: <breakpoint>:<pseudo-class>="<utility>"

  • 常见伪类: hover, focus, active, disabled, first, last, dark (暗黑模式)

  • 常见断点: sm, md, lg, xl

示例：一个响应式的、带交互状态的按钮 ​

html
<button
  p="y-2 x-4"
  bg="blue-500"
  text="white"
  font-semibold
  border="rounded-md"
  
  <!-- 交互状态 -->
  hover="bg-blue-600 shadow-md"
  focus="outline-none ring-2 ring-offset-2 ring-blue-400"
  disabled="opacity-50 cursor-not-allowed"

  <!-- 响应式：在中等屏幕(md)及以上，字体变大 -->
  md="text-lg"
  
  <!-- 组合使用：在大屏幕(lg)上 hover 时改变背景色 -->
  lg:hover="bg-green-500"
  
  <!-- 暗黑模式 -->
  dark="bg-gray-700 hover:bg-gray-600"
>
  Click Me
</button>

总结与最佳实践 ​

  1. 语义化优先: 将最能代表元素核心功能的样式属性化，如 flex, grid, bg。
  2. 保持简洁: 对于只有一两个工具类的简单情况，直接使用 class 可能更直接。
  3. 组合的力量: 属性化模式在处理伪类和响应式断点时最能大放异彩。
  4. [...] 是你的后盾: 遇到预设不支持的复杂 CSS 值时，大胆使用任意属性值 prop="[value]"。
